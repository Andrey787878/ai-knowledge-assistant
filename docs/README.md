# Документация проекта

Этот раздел служит точкой входа в рабочую документацию проекта. Здесь
собраны два инфраструктурных контура, отдельная документация по пути
поставки изменений и описание `n8n` workflow.

## Что входит в документацию

Документация разделена на три основных части:

- этап A: контур на четырех виртуальных машинах с Terraform, Ansible и Docker Compose;
- этапы B и C: контур на `k3s` с Helmfile, CI/CD и наблюдаемостью;
- `n8n` workflow: пользовательские и служебные сценарии агента.

## Основные разделы

### Этап A: Terraform, Ansible и Docker Compose

[Документация этапа A](./ansible_vm_deploy/README.md)

Этап A описывает развертывание на четырех виртуальных машинах: подготовку
инфраструктуры, сетевую модель, выпуск сертификатов, резервное копирование и
операционный цикл Ansible-деплоя.

### Этапы B и C: k3s, Helmfile, CI/CD и наблюдаемость

[Документация этапов B и C](./kubernetes_deploy/README.md)

Эта ветка документации покрывает Kubernetes-контур: bootstrap `k3s`,
Helmfile-слои, сетевые политики, наблюдаемость, SLI/SLO, алертинг и путь
доставки изменений через GitHub Actions.

### CI/CD этапов B и C

[Отдельный документ по CI/CD](./kubernetes_deploy/ci-cd.md)

Этот документ нужен, когда требуется посмотреть только на путь поставки
изменений: runner-VM, автоматическую и ручную выкладку, smoke-проверки и
правила запуска workflow.

### `n8n` workflow

[Документация по `n8n` workflow](../n8n/workflows/README.md)

Здесь описаны сценарии агента, память диалога, пользовательский интерфейс и
служебные workflow для smoke и импорта.
